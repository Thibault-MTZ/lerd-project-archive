# Archives de projets — état du module

Ce module est une base documentaire, sans fonctionnalité exécutable.
Il n'ajoute actuellement ni page, ni commande, ni action sur les projets.

Le futur parcours distinguera sauvegarde, archivage avec libération locale et
restauration. Les projets restaurés resteront arrêtés jusqu'à une reprise explicite.

Le manifeste est volontairement minimal. La version minimale de LERD et les
plateformes prises en charge seront déclarées après validation des capacités
réellement utilisées. Cette base n'est pas candidate au catalogue et n'a pas été
installée pour validation. Ne pas la considérer comme un outil de sauvegarde.

Voir le [plan](docs/PLAN.md) et les [limites techniques](docs/ARCHITECTURE.md).
